# daniellejsteer.com

Personal site for Danielle Steer. Hand-authored static HTML, no build step.

Built on the Tundra Ventures design system (see the brand kit's
`tundra-ventures-design-guidelines.md`): charcoal `#27343A`, deep teal
`#375F6D`, cool off-white `#E8EDF2`, warm orange `#FF9D27` as the sole
accent, Barlow as the documented free substitute for FF DIN, 0px corners,
orange triangle bullets.

## Files

- `index.html` — the whole site, one page, styles inline
- `assets/danielle-steer.jpg` — portrait by Bethany Birnie
- `assets/tundra-horizontal-reverse.svg` — Tundra lockup, white, for the affiliation band

## Before launch

`index.html` carries a `noindex, nofollow` robots tag so the GitHub Pages
preview stays out of search while the real domain still points at Lovable.
**Delete that meta tag when daniellejsteer.com is pointed here.**
